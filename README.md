# moex-paper-bot

Исследование торговых стратегий на Мосбирже и **бумажная торговля по реальным котировкам**: деньги виртуальные, цены настоящие. Бот торгует сам, без вашего участия, и показывает всё на странице-дашборде.

> Это не инвестиционная рекомендация. Прошлые результаты не гарантируют будущих. Реальные деньги подключаются только отдельным решением владельца.

## Что делает бот

- Каждые 30 минут в будни GitHub Actions запускает «тик»: скачивает свежие данные Мосбиржи (MOEX ISS), считает сигналы стратегий, исполняет виртуальные сделки, пересчитывает капитал.
- Состояние портфелей и страница-дашборд лежат в ветке `live`, GitHub Pages показывает их как сайт. На странице котировки ещё и обновляются раз в минуту прямо из браузера («прямой эфир»).
- Ведутся два портфеля (см. `config/portfolios.toml`):
  - **Защитный** — 1 000 ₽. Держит фонд на индекс Мосбиржи (TMOS@), пока индекс выше своей 150-дневной средней, иначе уходит в фонд денежного рынка (TMON@). Оба фонда на Т-Инвестициях торгуются без комиссии брокера. Главный кандидат для будущих реальных денег.
  - **Учебный: моментум акций** — 300 000 ₽. Раз в месяц покупает 5 акций с лучшим ростом за полгода. Для маленького капитала не подходит: у акций крупные лоты.
- **Риск-правила:**
  - «стоп-кран»: при просадке больше 20% от пика — 21 торговый день в денежном рынке;
  - **рекомендация вывода**: раз в квартал, если капитал вырос на 15% с прошлой отметки, вывести 50% прибыли сверх отметки. В бумажном режиме вывод «исполняется» автоматически, чтобы статистика была честной.

## Структура

| Путь | Что там |
|---|---|
| `src/tradebot/strategies.py` | Стратегии: по данным **до даты включительно** возвращают целевые веса портфеля |
| `src/tradebot/backtest.py` | Проверка на истории: сигнал по закрытию дня, сделка на следующий день, с издержками |
| `src/tradebot/risk.py` | Стоп-кран и правило вывода прибыли |
| `src/tradebot/paper.py` | Виртуальный портфель: лоты, комиссии, сделки, вывод |
| `src/tradebot/runner.py` | Один тик бота (`python -m tradebot.runner tick`) |
| `src/tradebot/iss.py`, `livedata.py` | Загрузка данных Мосбиржи (ISS, без токена) |
| `research/report.py` | Полное исследование → `docs/research-tables.md` и графики |
| `dashboard/index.html` | Страница-дашборд |
| `config/portfolios.toml` | Портфели, капитал, риск-правила |
| `data/*.parquet` | История: акции TQBR 2013–2021, индексы 2003–2021 (докачивается автоматически) |

## Запуск у себя (не обязательно)

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
pytest -q                     # тесты
python research/report.py     # исследование (1–2 минуты)
python -m tradebot.runner tick --state state   # один тик (нужен доступ к iss.moex.com)
```

Секретов и ключей проекту сейчас не нужно (`.env.example` пустой). Токен T-Invest понадобится только на этапе песочницы или реальной торговли.

## Источники данных

История 2003–2021 взята из открытого репозитория [nerevar/stock_prices](https://github.com/nerevar/stock_prices) (выгрузки MOEX ISS) и докачивается из [MOEX ISS](https://iss.moex.com). Ключевая ставка ЦБ зашита в `rates.py`. Ставки денежного рынка до 2013 года — грубые оценки.
