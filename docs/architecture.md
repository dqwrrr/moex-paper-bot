# Архитектура

Принцип: самая простая схема, которая работает бесплатно и без сервера.

## Как течёт информация

```text
Мосбиржа (MOEX ISS, бесплатно, задержка ~15 мин)
        ↓  раз в минуту, 09:50–23:55 МСК в будни (3 сессии по ≤ 5 ч 50 мин)
GitHub Actions: онлайн-сессия бота
   ├─ обновить данные (кэш Actions)
   ├─ стратегия → целевые веса
   ├─ риск-правила (стоп-кран, вывод прибыли)
   ├─ виртуальные сделки по текущим ценам
   ├─ сводки 12:00 / 15:00 / 18:45 / 23:45 → лента + Telegram
   └─ каждые ~3 мин состояние → ветка live (один коммит, без истории)
        ↓
GitHub Pages (страница из ветки site) → вы в браузере
   └─ каждые 2 мин читает site.json из ветки live через GitHub API, раз в минуту — цены с Мосбиржи
```

```text
GitHub (main) → CI: ruff + pytest на каждый push
             → «Бумажная торговля» по расписанию → ветка live → Pages
             → «Обновить историю» раз в день → кэш данных (+ ветка data при ручном запуске)
```

Простыми словами:
- **Сервера нет.** Роль сервера выполняет GitHub Actions: бесплатный запуск кода по расписанию, для публичных репозиториев без лимита минут.
- **Базы данных нет.** Состояние портфеля — маленькие JSON-файлы в ветке `live`. Каждое изменение сохраняется коммитом, поэтому есть полная история и защита от подделки задним числом.
- **История котировок** хранится в кэше Actions (Parquet — сжатый табличный формат). Если кэш пропадёт, бот заново скачает всё с биржи.

## Модули

| Модуль | Ответственность |
|---|---|
| `data.py` | Загрузка истории; `Market.upto(date)` отдаёт срез без будущего |
| `strategies.py` | Чистые функции «данные → веса»; одна и та же функция работает в бэктесте и в живом режиме |
| `backtest.py` | Историческая проверка: сигнал в день t, исполнение по закрытию t+1, издержки, кэш по ключевой ставке |
| `risk.py` | Стоп-кран по просадке, правило вывода прибыли |
| `paper.py` | Виртуальный портфель: лоты, комиссии, проскальзывание, сделки, вывод |
| `runner.py` | Тик: данные → риск → сигнал → исполнение → оценка → `site.json` |
| `iss.py`, `livedata.py` | Клиент MOEX ISS, пополнение истории |

## Отображение стратегий на реальные бумаги

| Ключ в стратегии | Бумага | Режим торгов | Комиссия брокера (Т-Инвестиции) |
|---|---|---|---|
| `INDEX` | TMOS (Т-Капитал Индекс МосБиржи) | TQTF | 0 |
| `CASH` | TMON (Т-Капитал Денежный рынок) | TQTF | 0 |
| тикер акции | акция | TQBR | 0,05% (тариф «Трейдер») + 0,05% проскальзывание |

## Безопасность

- Секретов нет: ISS не требует токена, реальные деньги не задействованы.
- Бот не умеет выводить деньги и не имеет доступа к брокерскому счёту.
- Когда появится T-Invest, токен будет только в GitHub Secrets, с правами «только песочница» или «только торговля без вывода средств».

## Путь к реальным деньгам (будущее)

1. Бумажная торговля минимум 3–6 месяцев, сравнение с бэктестом.
2. Песочница T-Invest: тот же код через интерфейс брокера (нужен токен песочницы).
3. Реальный счёт с маленькой суммой — только после отдельного решения владельца.
