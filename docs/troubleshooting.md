# Если что-то сломалось

| Симптом | Причина | Что делать |
|---|---|---|
| Workflow «Бумажная торговля» красный, в логе `ISS недоступен` | Мосбиржа не отвечает или блокирует серверы GitHub | Перезапустить позже. Если повторяется постоянно — перенести запуск на свой компьютер или VPS (см. ADR 0001) |
| `Нет цены для TMOS` | Биржа сменила тикер или режим торгов | Поправить `INSTRUMENTS` в `src/tradebot/paper.py` |
| Сайт пустой или 404 | Pages не включён или ещё нет ветки `live` | Settings → Pages → Branch: `live` / root. Запустить «Бумажная торговля» вручную |
| Ошибка push `Permission denied` в Actions | Нет прав на запись у workflow | Settings → Actions → General → Workflow permissions → Read and write |
| Тики перестали идти | GitHub отключил расписание (60 дней без активности) | Actions → нужный workflow → Enable workflow |
| Долгий первый тик моментума | Докачивается история акций с 2021 года | Сначала вручную запустить «Обновить историю котировок» |

## Восстановление с нуля
1. Клонировать репозиторий. Вся логика и история лежат в `main`, состояние портфелей — в ветке `live`.
2. Если ветка `live` потеряна, первый же тик создаст новые портфели со стартовым капиталом.
3. Если потерян кэш данных, workflow «Обновить историю котировок» скачает всё заново (до ~30 минут).
