# ADR 0001: бумажная торговля на GitHub Actions + Pages, данные MOEX ISS

**Контекст.** Нужен бот, который торгует виртуальными деньгами по реальным ценам, работает без присмотра и показывает результат. Бюджет нулевой.

**Варианты.**
1. VPS в РФ (300–600 ₽/мес) + база данных + веб-сервер.
2. Песочница T-Invest сразу: нужен токен, а доступность API с серверов GitHub не проверена.
3. GitHub Actions по расписанию + JSON-состояние в git + GitHub Pages, данные из MOEX ISS без токена.

**Решение.** Вариант 3: 0 ₽, нет секретов, полная история в git.

**Последствия.**
- Pages бесплатен только для публичных репозиториев, поэтому код и сделки видны всем. Для бумажного этапа это приемлемо.
- Расписание Actions может запаздывать на 5–20 минут. Для дневных стратегий не критично.
- В публичном репозитории GitHub отключает расписание после 60 дней без активности. Коммиты бота в `live` считаются активностью, но это нужно проверять.
- Если серверы GitHub не смогут достучаться до iss.moex.com, запасной план — запуск на компьютере владельца или на VPS.
