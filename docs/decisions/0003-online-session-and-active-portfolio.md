# ADR 0003: онлайн-сессия, активный портфель, правило «тела»

**Контекст.** Владелец хочет частые сделки, комментарии каждые несколько минут, сводки каждые несколько часов и выбор между долгосрочным и активным режимами в интерфейсе.

**Варианты.**
1. Cron каждые 5 минут — GitHub часто задерживает запуски на 5–20 минут, лишние установки окружения.
2. VPS с постоянно работающим процессом — стоит денег.
3. Долгая «сессия» в GitHub Actions: 3 запуска в день по ≤ 5 ч 50 мин (лимит задачи — 6 ч), внутри цикл раз в минуту.

**Решение.** Вариант 3. Состояние публикуется в `live` коммитом с `--amend` и принудительной отправкой (ветку пишет только бот), чтобы репозиторий не рос. Страница — в отдельной ветке `site`, чтобы частые публикации не запускали пересборку Pages (у Pages лимит ~10 сборок в час). Данные страница берёт из `live` через GitHub API (лимит 60 запросов в час на IP, страница делает 30).

**Правило «тела»** для активного портфеля: в каждой сводке, если капитал ≥ тело × (1 + 2%), вся прибыль сверх тела рекомендуется к выводу (в бумажном режиме — выводится), торговля продолжается с телом.

**Последствия.** Данные ISS с задержкой ~15 минут — бот живёт «на 15 минут в прошлом», это честно для бумажной торговли. Для реальной торговли понадобятся котировки T-Invest без задержки. Между сессиями возможны разрывы в несколько минут.
