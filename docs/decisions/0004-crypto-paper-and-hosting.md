# ADR 0004: бумажная крипта и где жить боту

**Контекст.** Владелец хочет торговать криптой (в перспективе — через экосистему Telegram) и видеть сделки круглосуточно. Цель «×2 в день» нереалистична: при таком темпе 10 $ за 30 дней превратились бы в ~10 млрд $; стратегии, которые обещают подобное, — плечо и лотерея с почти гарантированной потерей депозита.

**Решение.**
- Крипто-портфель — только бумажный: BTC против USDT на часовых свечах, без плеча, капитал 10 $, правило «тела» (+5%), дневной лимит убытка −5%. Данные — публичные Binance (data-api.binance.vision), без ключей.
- Стратегию выбирает исследование «подбор 2020–2023 / проверка 2024–2026» с комиссией 0,15% на сторону.
- Telegram Wallet не используется как площадка для бота: это кошелёк без биржи и без официального торгового API. Для возможной реальной торговли в экосистеме TON — отдельный некастодиальный кошелёк и DEX (STON.fi), только по решению владельца.
- Сессия бота работает 24/7: запуск каждые 6 часов, внутри — шаг раз в минуту.

**Риск хостинга.** Правила GitHub Actions запрещают использовать его как «бессерверные вычисления», не связанные со сборкой/тестированием проекта. Круглосуточный бот — серая зона: GitHub может отключить Actions в репозитории. На бумажном этапе приемлемо; для долгой работы и тем более реальных денег — перенос на VPS (~200–400 ₽/мес) или свой компьютер. Код переносим без изменений (`python -m tradebot.runner session`).
